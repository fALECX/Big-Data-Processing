Week 3 Step-by-Step Guide

Open three Terminal windows on your macOS machine:

Terminal 1: On your local machine.
Terminal 2: SSH into your jumphost.
Terminal 3: SSH into your EMR master node (from the jumphost).

========================
Terminal 1 Local Machine
========================
Download mapper.py, reducer.py, run-5.sh, and 3littlepigs.txt
By default, macOS saves downloaded files in your ~/Downloads directory.

Run the following commands:

    cd ~/Downloads
    mkdir w3
    mv mapper.py reducer.py run-5.sh 3littlepigs.txt w3/
    ls -l w3/

Explanation:
• Change to the Downloads directory
• Create w3 dirctory.
• Move four files into the w3 directory
• List the contents of w3.

Copy the entire w3 directory from your local machine to the home directory of 
your jumphost:
    
    scp –r ~/Downloads/w3 jumphost:~/

Explanation:

• scp -> secure copy over SSH
• -r  -> recursively copy a directory and all its contents
• ~/Downloads/w3  -> source directory on your local machine
• jumphost:~/. -> destination
  jumphost is the SSH host alias (defined in ~/.ssh/config)
  ~/ is the remote user's home directory (/home/ec2-user)

===================
Terminal 2 Jumphost
===================

    cd
    ls w3/

Run the following command to copy `w3 from your jumphost 
to your EMR master node home directory:

    scp -i s4271512-cosc2637.pem -r w3 hadoop@s4271512.emr.cosc2637.route53.aws.rmit.edu.au:~/

=====================
Terminal 3 EMR Master
=====================

Go to the w3 directory (under your home directory):
    cd ~/w3

You can confirm your current location with:
    pwd

Displays the contents of the current directory w3:    
    ls

Upload 3littlepigs.txt to the root directory of HDFS and then list the contents of 
your current HDFS directory:

   hadoop fs –put 3littlepigs.txt /
   hadoop fs –ls /

Make the file run.sh executable; and run your first MapReduce job on the master node:

   chmod +x run-5.sh
   ./run-5.sh

Display the contents of the output files generated by a MapReduce job in HDFS.
/output/
├── part-00000
├── part-00001
└── part-00002

Display the contents of each reducer ouput file:

   hadoop fs -cat /output/part-00000
   hadoop fs -cat /output/part-00001
   hadoop fs -cat /output/part-00002 

Display all part files:

   hadoop fs -cat /output/part* 

Merge all Hadoop output files in HDFS into one local file called merged_output.txt:
   
   hadoop fs –getmerge /output/part* merged_output.txt
   cat merged_output.txt
